Mill Smart Log — Design System

Sistem manajemen operasional pabrik CPO (mill) yang mendigitalisasi log sheet stasiun produksi (Weighbridge, Grading, Cages & Track) — Operator menginput data via mobile offline-first, sementara Supervisor, Mill Management, dan Admin mengelola dan memonitor melalui web. Referensi visual berikut dipakai konsisten di seluruh layar web dan mobile.
