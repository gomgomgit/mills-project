Component Pattern Notes

data-table
Sortable columns (klik header), fixed header saat scroll, row hover highlight pastel soft, pagination 10/25/50 di kanan bawah, filter collapsible menggunakan Alpine.js transition, striped rows alternasi halus (white/surface) untuk readability.
form
Field error: border merah + pesan error inline di bawah input + icon warning. Validasi real-time via Alpine.js (cek saat blur). Tombol submit di kanan bawah. Toast notification: hijau (success), merah (error), auto-dismiss 4 detik. Field label selalu terlihat, tidak floating.
toast
Slide-in dari kanan atas. Warna: hijau (#86BF9A background) untuk success, merah (#ef4444) untuk error, kuning (#F5C5A3) untuk warning, auto-dismiss 4 detik. Icon Lucide sesuai tipe (check, alert-triangle, x).
loading
Skeleton shimmer untuk halaman (card, rows, chart) dengan warna abu-abu pastel (#E7E5E4 shimmer). Button loading: spinner dalam tombol (disabled, opacity 70%). Loading di dalam card gunakan mini spinner.
